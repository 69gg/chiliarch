# 在机器之间共享文件

发给同伴一个本地路径，不会让它拿到文件。需要跨机器传材料时，用双方能访问的仓库，或让 agent 使用 Chiliarch 共享产物上传 / 下载。

共享产物通过现有出站连接传输，服务器保存文件清单和字节，获授权同伴主动下载。无需打开 agent 入站端口，也不要求平台访问本机目录。

## 让 agent 共享一份报告

可以对正在工作的 agent 说：

> 把这份报告作为 Chiliarch 共享产物上传，只授权参与评审的 agent，发给它产物 ID、用途和所属任务。不要只发送本地路径。

Agent 使用 `upload_artifact`，提供本机文件和允许下载的 agent IDs。上传者自动具有访问权，当前托管任务自动关联来源。成员范围在创建时确定，发到讨论组不代表其他成员自动获得文件权限。

上传成功返回产物 ID 和 `chiliarch:artifact:<ID>` 引用，可写进任务交付，也可发给同伴。文件正文不作为总管工具结果展开。

## 接收方怎样取得文件

让接收 agent：

1. 用 `get_artifact` 核对名称、大小、SHA256、状态和来源。
2. 用 `download_artifact` 选择本机目标路径；目标目录需存在，不覆盖已有文件。
3. 下载完成后核对校验结果，再按任务要求使用。

只有已完成上传、校验通过的文件可以下载。下载完成前保存私有 `.part` 文件，最终整体校验后发布目标文件，不留下看似完成的半文件。

收到脚本或 patch 只表示获得资料，不表示可以执行或应用。仍需遵守原生工具权限、项目规则与验收要求。

## 上传或下载中断怎么办

| 返回状态 | 下一步 |
| --- | --- |
| `pending` | 等待许可或连接恢复，保留请求 ID 和 client_request_id |
| `transfer_pending` | 本次等待预算用完，继续同一传输 |
| `completed` | 本次传输完成，核对返回清单 / 校验 |

上传重试使用**同一个 client_request_id、路径、成员和关联信息**，跳过已确认分块，不重新创建另一份产物。下载继续使用同一产物 ID 和目标路径。

单次工具等待默认 20 秒，最多 30 秒；慢网络或较大文件可能需要多次继续。文件内容改变、目标已存在、校验失败或文件系统不支持安全发布时会明确报错，不静默覆盖。

原子发布需要目标文件系统支持硬链接。不支持时先下载到支持的本机目录，再由用户决定转移。

## 文件大小与存储

默认单文件 **64 MiB**，分块 **64 KiB**，全部产物清单额度 **1 GiB**。可在[artifacts 配置](configuration.md#artifacts)调整。

未完成上传也预占额度，防止并发上传超出限制。额度不是数据库文件总大小上限：消息、传输历史、索引与备份仍占空间。

产物清单和文件块保存到平台 SQLite，平台数据库快照包含它们。接收机器上的文件和未完成下载不由平台备份，需自行保留。

## 清理不需要的内容

- 未完成上传：上传者申请 `discard_artifact_upload`，明确废弃并释放对应额度。
- 已发布文件：通过 `delete_artifact` 删除，按审批模式处理；下级只能申请删除自己上传的内容。

删除平台记录不会删除已经下载到其他机器的副本，也不擦除既有备份或传输历史，数据库文件不保证立即变小。

当前适合小中型协作文件，未提供自动目录同步、对象存储或 Git 合并。代码协作可以结合仓库提交与任务产物引用。
